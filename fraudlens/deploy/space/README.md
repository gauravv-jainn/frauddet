# FraudLens

Explainable credit card fraud scoring: a calibrated LightGBM model, a 0-999 risk score, plain-English reasons and an
analyst case queue. Sign-in is required. Data is synthetic.

Source, evaluation and report: https://github.com/gauravv-jainn/frauddet/tree/main/fraudlens

This free Space has no persistent disk, so cases and accounts created in the app reset whenever it restarts.
