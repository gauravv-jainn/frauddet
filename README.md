# Credit Card Fraud Detection (ML mini project)

Reproduces and critiques *Credit Card Fraud Detection Using Machine Learning* (Tanouz et al., ICICCS 2021), then extends it.
Gaurav Jain (D12B, Roll 20) and Palash Matani (D12B, Roll 38), VESIT Mumbai.

## What is here
- `CreditCard_Fraud_MiniProject.ipynb`: one-go Colab notebook (Run all). Parts A-D reproduce the paper and fix its evaluation flaws
  (preprocessing before the split, tiny balanced test set, "ROC-AUC" computed from hard labels). Part E is the production-style pipeline:
  past-to-future split, tuned XGBoost, Platt calibration, money-aware threshold, SHAP, and export of `fraud_detector.html`.
- `fraud_detector.html` (generated by Part E, not committed): offline FraudShield app. Overview dashboard, transaction checker with what-if,
  live monitor with analyst queue, model insights. The trained trees run inside the page in JavaScript.
- `fraudshield/`: readable copies of the pipeline code and the app template that Part E embeds.
- `docs/`: literature review (Word and PDF) and two presentations.

## Run
Open the notebook in Google Colab, Runtime -> Run all, then open the downloaded `fraud_detector.html`.
Locally: `python3 -m venv .venv && source .venv/bin/activate && pip install numpy pandas scikit-learn imbalanced-learn xgboost matplotlib lime jupyter kagglehub`, then `jupyter notebook`.

## Limits
One public dataset (two days of European card transactions, PCA-anonymised features). Educational demo, not for real transactions.
